About Anaemia AI

A research prototype for anaemia prediction from CBC values

Project Overview

HemaScope XAI predicts anaemia from manually entered CBC values or a text-based PDF.

The active predictor is PyTorch. The project retains the SVM implementation and artifacts for historical reference, with no automatic fallback.

Key Innovations
XAI Integration

The historical SVM notebook includes SHAP and counterfactual experiments. The site displays their static examples.

Risk Index

The app combines input values into a rule-based risk index for display.

Evaluation Scope

PyTorch was evaluated on 107 held-out records. Independent clinical validation has not been performed.

Server Processing

Manual inputs and uploaded PDFs are sent to the hosted Flask server for processing. Use de-identified reports.

Technical Architecture
Machine Learning Core

PyTorch inference with a saved scaler for manual and PDF predictions

Explainability Layer

Static SHAP and counterfactual examples from the legacy SVM notebook

Prediction Interface

Manual CBC form and text-based PDF upload

Project Components
Prediction Workflow
  • Manual Entry: CBC measurements
  • PDF Upload: Text extraction from uploaded reports
  • Inference: Shared PyTorch prediction pipeline
  • Result: Prediction, confidence score, and risk index
