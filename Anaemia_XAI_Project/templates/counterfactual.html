Understanding Counterfactual Reasoning

Counterfactual analysis explores how hypothetical changes to model inputs can change a prediction.

This page shows a static chart from the historical SVM notebook and illustrative examples. Live PyTorch requests do not generate individualized counterfactuals.

Scope: A change in model output does not show that changing a blood measurement would improve a health outcome.

How to Interpret Counterfactual Examples
Historical SVM Notebook

The historical notebook explored how varying input features could change its SVM classification.

  • Input changes are hypothetical
  • Results depend on the model and the example
  • The chart is a static notebook output
Scope of Live Predictions

The live application uses a separate PyTorch model.

  • Manual and PDF requests return a classification
  • No per-request counterfactual optimization
  • No estimated treatment timelines
  • No treatment targets from these examples
