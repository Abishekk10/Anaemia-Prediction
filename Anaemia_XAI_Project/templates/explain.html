Explainable AI with SHAP

A static feature-attribution example from the historical SVM notebook

What is SHAP?

SHAP (SHapley Additive exPlanations) is a game theory approach to explain the output of any machine learning model.

The historical SVM notebook used SHAP to estimate how blood parameters contributed to its model outputs.

Scope: This example describes the historical SVM experiment. Live PyTorch predictions do not generate per-request SHAP explanations.

Using the Historical Example
Model Attribution

SHAP estimates how input features contributed to an output relative to a baseline.

Clinical Scope

Feature attribution does not establish clinical validity.

Educational Value

Medical professionals and students can learn about complex relationships in hematological data.

Interpretation Limits

Feature attributions describe model behavior. They do not establish causation.
