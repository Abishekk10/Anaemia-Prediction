Transparent Anaemia Prediction System using Explainable & Counterfactual AI
Overview:

An AI-powered web application that predicts anaemia using hematological parameters from CBC reports. The system combines Support Vector Machine (SVM), SHAP explainability, and counterfactual analysis to provide transparent predictions and actionable insights.

Features:
Anaemia prediction using SVM
SHAP-based feature importance analysis
Counterfactual recommendations
Confidence score and risk assessment
Clinical recommendations and precautions
Interactive dashboard and visualizations

Tech Stack:
Python
Flask
Scikit-learn
SHAP
Pandas
HTML, CSS, JavaScript
Matplotlib

Workflow:
Enter CBC parameters (Hb, MCV, MCH, MCHC, Gender)
Model predicts Anaemic / Non-Anaemic
SHAP explains prediction
Counterfactual analysis suggests improvements
Dashboard displays insights and recommendations

Dataset:
Publicly available Anaemia Dataset containing hematological parameters and anaemia labels.

Future Scope:
Hospital data integration
Multi-disease prediction
Cloud deployment
Enhanced clinical decision support
